# Einzelnoten lesen

## Was du hier lernst

Du lernst, jede Note im Violin- und Bassschlüssel **sofort** zu erkennen – nicht durch Abzählen von unten, sondern über ein paar feste **Orientierungsnoten**, von denen aus du nur noch ein, zwei Schritte gehst.

## Warum das fürs Blattspiel zählt

Beim Blattspiel bleibt keine Zeit zum Buchstabieren. Wer die Orientierungsnoten sicher kennt, findet jede andere Note mit einem kurzen Seitenblick – und hat den Kopf frei für Rhythmus und Ausdruck.

## Linien und Zwischenräume

Das **Notensystem** hat fünf Linien; gezählt wird **von unten**. Jede Note steht entweder **auf** einer Linie oder **in** einem Zwischenraum. Ein Schritt von Linie zu Zwischenraum ist ein Ton weiter im Alphabet: C, D, E, F, G, A, H.

> Violinschlüssel, Linien: **E**s **g**eht **h**urtig **d**urch **F**leiß (E G H D F) – Zwischenräume: **F A C E**.

> Bassschlüssel, Linien: **G**eh **h**in, **d**u **f**aule **A**meise (G H D F A) – Zwischenräume: **A**lle **C**owboys **e**ssen **G**ras.

## Die Orientierungsnoten

Die Schlüssel selbst verraten zwei davon: Der **Violinschlüssel** heißt auch G-Schlüssel, weil er sich um die G-Linie (G4) kringelt. Der **Bassschlüssel** heißt F-Schlüssel – seine zwei Punkte umschließen die F-Linie (F3).

```noten
system: treble
noten: C4 G4 C5 F5 C6
text: Violinschlüssel: C4 (Hilfslinie), G4 (G-Schlüssel), C5, F5 (oberste Linie), C6
```

```noten
system: bass
noten: C2 G2 C3 F3 C4
text: Bassschlüssel: C2, G2 (unterste Linie), C3, F3 (F-Schlüssel), C4 (Hilfslinie)
```

Merke dir besonders die **Cs**: Im Violinschlüssel liegt C4 auf der ersten Hilfslinie unten, C5 im dritten Zwischenraum, C6 auf der zweiten Hilfslinie oben. Im Bassschlüssel spiegelt sich das: C4 auf der ersten Hilfslinie oben, C3 im zweiten Zwischenraum, C2 auf der zweiten Hilfslinie unten.

## Das Klaviersystem

Im **Klaviersystem** stehen Violin- und Bassschlüssel übereinander, verbunden durch eine geschweifte Klammer. **C4**, das „eingestrichene c“ in der Mitte der Klaviatur, liegt genau dazwischen: eine Hilfslinie unter dem oberen System oder eine Hilfslinie über dem unteren – es ist dieselbe Taste.

```noten
system: grand
noten: C4
text: C4 – die Mitte: hier im oberen System notiert
```

## Hilfslinien und 8va

Über und unter dem System geht es mit kurzen **Hilfslinien** weiter. Ab vier Hilfslinien wird es unübersichtlich – dann schreibt man die Noten eine Oktave tiefer und setzt **8va** darüber („eine Oktave höher spielen“), unten entsprechend **8vb**.

```noten
system: treble
noten: A5 C6 E6 G6
text: Eine bis vier Hilfslinien über dem Violinschlüssel: A5, C6, E6, G6
```

## Vorzeichen

- Ein **Kreuz** (♯) erhöht eine Note um einen Halbton: aus F wird Fis.
- Ein **b** (♭) erniedrigt um einen Halbton: aus E wird Es, aus H wird B.
- Ein **Auflösungszeichen** (♮) hebt ein Vorzeichen wieder auf.

Ein Vorzeichen vor einer Note gilt bis zum Ende des Takts – für dieselbe Note in derselben Oktave.

```noten
system: treble
noten: F#4 Bb4 F4
text: Fis, B und F mit Auflösungszeichen
```

## Übungstipp

Lies jede Note **vom nächsten Anker aus**: „zwei über G“, „eins unter C“. Nach einiger Zeit siehst du die Note direkt – der Zwischenschritt verschwindet von allein.
